Tentang Elara

Asisten AI pribadi yang dibangun dengan penuh dedikasi oleh kumunitas, dari Indonesia, dalam waktu 2–3 hari. Ringan, cepat, lengkap, dan tanpa framework berat.

Elara bukan produk perusahaan besar — ia lahir dari rasa penasaran dan kerja keras Gilang Armanda Putra, seorang pemuda 19 tahun, lulusan SMK, yang membangun seluruh sistem ini dalam waktu hanya 2–3 hari. Mulai dari desain antarmuka, pemilihan arsitektur, orkestrasi puluhan model AI, hingga lapisan keamanan — semuanya dirancang dan ditulis sendiri.

Tujuannya sederhana: menghadirkan asisten AI yang cepat, bisa diandalkan, dan tetap ringan — tanpa iklan, tanpa pelacakan, tanpa biaya untuk pengguna.

Arsitektur & Teknologi

Elara dibangun dengan pendekatan single-file application — seluruh antarmuka, logika, dan state manajer berada dalam satu file HTML. Tanpa bundler, tanpa npm install, tanpa framework. Cukup buka di browser, langsung jalan.

  • Frontend — HTML5 + CSS3 vanilla (custom properties, grid, flexbox), JavaScript ES2020+, tanpa dependency runtime.
  • Backend / Proxy — Cloudflare Workers (serverless edge runtime), sebagai perisai antara browser dan penyedia AI.
  • Streaming — Server-Sent Events (SSE) dari setiap provider, di-parse bertahap agar jawaban muncul seolah diketik.
  • Penyimpanan — localStorage di sisi klien untuk riwayat chat, preferensi model, tema, dan (opsional) API key milik pengguna.
  • Render — Markdown parser buatan sendiri, plus KaTeX untuk matematika dan highlight.js untuk blok kode.
Mengapa pakai Cloudflare Worker sebagai proxy? Karena kunci API tidak boleh bocor ke browser. Browser hanya bicara ke Worker; Worker yang menyisipkan rahasia dan meneruskan permintaan ke provider asli. Bonusnya: menghindari CORS, rotasi otomatis, dan menyembunyikan infrastruktur.

Keamanan & Privasi

  • API key tidak pernah bocor — semua key utama disimpan sebagai Secret di environment Cloudflare Worker, bukan di HTML.
  • Mode fallback — jika kamu ingin memakai key sendiri, isian di modal "API key" hanya disimpan di localStorage browser kamu dan dikirim langsung ke provider. Tidak pernah menyentuh server Elara.
  • Tanpa pelacakan — tidak ada analytics, tidak ada cookie pihak ketiga, tidak ada telemetri.
  • Data tetap milikmu — seluruh riwayat obrolan tersimpan lokal dan bisa kamu hapus kapan saja.
  • Sanitasi HTML — semua jawaban model di-escape sebelum dirender, mencegah injeksi skrip.
Catatan penting Elara hanyalah antarmuka. Jawaban sepenuhnya berasal dari model AI pihak ketiga dan bisa saja keliru. Selalu verifikasi informasi penting dari sumber terpercaya.

Cara Pakai (untuk Pengguna)

  1. Pilih model — klik tombol model di pojok kanan atas header, pilih provider & model sesuai kebutuhan.
  2. Ketik pertanyaan di kolom pesan bawah. Tekan Enter untuk kirim, Shift+Enter untuk baris baru.
  3. Lampirkan gambar (opsional) — klik ikon klip. Model dengan tag Vision bisa membacanya.
  4. Kelola obrolan — hover item di sidebar untuk sematkan, ganti nama, atau hapus. Di HP, swipe kiri item obrolan untuk memunculkan konfirmasi hapus.
  5. Edit pesan terakhir — klik tombol "Edit" di pesanmu untuk memperbaiki & mengirim ulang.
  6. Regenerasi jawaban — tombol "Ulangi" di bawah jawaban terakhir.
  7. Ganti tema — klik ikon bulan/matahari di header. Pilihan tema disimpan otomatis.
  8. Shortcut — Ctrl/Cmd + K untuk obrolan baru, Esc untuk menutup menu/modal.

Setup Cloudflare Proxy (untuk Developer)

Ingin fork Elara dan hosting sendiri? Berikut jalur cepat untuk menyiapkan proxy Cloudflare Worker yang menyembunyikan API key.

  1. Buat akun gratis di dash.cloudflare.com.
  2. Buka menu Workers & Pages → Create → Worker, beri nama misal elara-proxy.
  3. Edit Worker, tempel skrip proxy-mu — buat router sederhana yang meneruskan /groq/*, /gemini/*, /openrouter/*, dst. ke endpoint provider masing-masing.
  4. Buka tab Settings → Variables and Secrets, tambahkan secret: GEMINI_KEY, GROQ_KEY, OPENROUTER_KEY, MISTRAL_KEY, INFERX_KEY, ZRO_KEY, NVIDIA_KEY, POLLINATIONS_KEY. Nilai jangan ditulis di kode — hanya di sini.
  5. Deploy Worker → salin URL-nya (contoh https://elara-proxy.username.workers.dev).
  6. Di file HTML Elara, cari baris const WORKER_BASE = "...", ganti dengan URL Worker-mu.
  7. Buka Elara di browser — selesai. Semua panggilan AI kini lewat proxy-mu sendiri.
Tips Aktifkan rate limiting di Worker (mis. 30 req/menit per IP) supaya tidak disalahgunakan orang lain saat URL dibagikan.

Kredit, Biaya & Kuota

Elara sepenuhnya gratis untuk pengguna. Tidak ada langganan, tidak ada iklan, tidak ada paywall tersembunyi. Semua biaya ditanggung lewat free tier masing-masing provider:

  • Groq — gratis dengan rate limit harian.
  • OpenRouter — model bertanda :free gratis, kadang antre.
  • Google Gemini — kuota gratis harian dari AI Studio.
  • Cloudflare Workers AI — kuota gratis bulanan.
  • Zro MoonMath — free plan reset tiap hari.
  • InferX — promo gratis 100% untuk periode terbatas.
  • Pollinations — akses gratis via key sekunder.
  • NVIDIA NIM & Mistral — free tier untuk eksperimen.

Jika ingin performa lebih stabil atau model premium, kamu bisa mendaftar langsung ke provider dan memasukkan API key sendiri lewat tombol "Masukkan API key" di sidebar.
