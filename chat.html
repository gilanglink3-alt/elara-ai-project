Tentang Elara

Elara adalah aplikasi asisten AI berbasis web. Aplikasi ini mendukung beberapa penyedia model, dapat membaca gambar pada model yang mendukung, dan menyimpan riwayat percakapan secara lokal

Elara tidak menampilkan iklan, tidak melacak penggunanya, dan dapat dipakai tanpa biaya.

Arsitektur dan Teknologi

Elara berupa satu file HTML. Tampilan, logika, dan pengelolaan data ada di file yang sama. Tidak perlu npm install, cukup buka di browser.

  • Frontend: HTML, CSS, dan JavaScript biasa tanpa framework.
  • Proxy: Cloudflare Workers, sebagai perantara antara browser dan penyedia AI.
  • Streaming: jawaban dari tiap provider dibaca bertahap lewat SSE, jadi muncul sambil diketik.
  • Penyimpanan: riwayat chat, pilihan model, tema, dan API key opsional disimpan di localStorage browser.
  • Tampilan jawaban: parser Markdown buatan sendiri, KaTeX untuk rumus, dan highlight.js untuk kode.
Kenapa pakai Cloudflare Worker? Supaya API key tidak ada di browser. Browser hanya bicara ke Worker, lalu Worker menambahkan key dan meneruskan permintaan ke provider. Cara ini juga menghindari masalah CORS.

Keamanan dan Privasi

  • API key tidak ada di browser. Key utama disimpan sebagai Secret di Cloudflare Worker, bukan di HTML.
  • Pakai key sendiri. Key yang kamu isi di modal "API key" hanya disimpan di localStorage browsermu.
  • Tanpa pelacakan. Tidak ada analytics atau cookie pihak ketiga. Satu-satunya panggilan tambahan adalah ke Supabase untuk mengambil ide prompt di halaman awal, dan tidak ada isi obrolanmu yang ikut terkirim.
  • Data milikmu. Riwayat obrolan tersimpan lokal dan bisa kamu hapus kapan saja.
  • Teks di-escape. Semua jawaban model diamankan dulu sebelum ditampilkan, supaya tidak ada skrip yang bisa jalan.
Catatan Elara hanya antarmuka. Jawaban datang dari model AI pihak ketiga dan bisa saja salah. Cek ulang informasi yang penting.

Cara Pakai

  1. Pilih model. Klik tombol model di kanan atas, lalu pilih provider dan model.
  2. Ketik pertanyaan di kolom bawah. Enter untuk kirim, Shift+Enter untuk baris baru.
  3. Lampirkan gambar (opsional) lewat ikon klip. Hanya model dengan kemampuan vision yang bisa membacanya.
  4. Kelola obrolan. Arahkan kursor ke obrolan di sidebar untuk menyematkan, mengganti nama, atau menghapus. Di HP, geser obrolan ke kiri untuk menghapus.
  5. Edit pesan. Klik "Edit" di pesanmu untuk memperbaiki dan mengirim ulang.
  6. Ulangi jawaban. Pakai tombol "Ulangi" di bawah jawaban terakhir.
  7. Ganti tema. Klik ikon bulan di header. Pilihanmu disimpan otomatis.
  8. Shortcut. Ctrl/Cmd + K untuk obrolan baru, Esc untuk menutup menu atau jendela.

Setup Cloudflare Proxy (untuk Developer)

Mau fork Elara dan hosting sendiri? Ini langkah singkat untuk menyiapkan proxy Cloudflare Worker.

  1. Buat akun gratis di dash.cloudflare.com.
  2. Buka Workers & Pages, pilih Create lalu Worker, dan beri nama misalnya elara-proxy.
  3. Edit Worker dan tempel skrip proxy. Buat router sederhana yang meneruskan /groq/*, /gemini/*, /openrouter/*, dan seterusnya ke endpoint provider masing-masing.
  4. Buka Settings lalu Variables and Secrets, dan tambahkan secret: GEMINI_KEY, GROQ_KEY, OPENROUTER_KEY, MISTRAL_KEY, INFERX_KEY, ZRO_KEY, NVIDIA_KEY, POLLINATIONS_KEY. Jangan tulis nilainya di kode.
  5. Deploy Worker, lalu salin URL-nya (contoh https://elara-proxy.username.workers.dev).
  6. Di file HTML Elara, cari baris const WORKER_BASE = "..." dan ganti dengan URL Worker-mu.
  7. Buka Elara di browser. Semua panggilan AI sekarang lewat proxy-mu sendiri.
Saran Aktifkan rate limiting di Worker (misalnya 30 permintaan per menit per IP) supaya tidak disalahgunakan kalau URL-nya dibagikan.

Biaya dan Kuota

Elara gratis untuk pengguna. Tidak ada langganan dan tidak ada iklan. Biayanya ditanggung lewat free tier masing-masing provider:

  • Groq: gratis dengan batas harian.
  • OpenRouter: model bertanda :free gratis, kadang harus antre.
  • Google Gemini: kuota gratis harian dari AI Studio.
  • Cloudflare Workers AI: kuota gratis bulanan.
  • Zro MoonMath: paket gratis, kuota reset tiap hari.
  • InferX: promo gratis untuk periode terbatas.
  • Pollinations: akses gratis lewat key sekunder.
  • NVIDIA NIM dan Mistral: free tier untuk percobaan.

Kalau mau performa lebih stabil atau model premium, kamu bisa daftar langsung ke provider dan memasukkan API key sendiri lewat tombol "Masukkan API key" di sidebar.
